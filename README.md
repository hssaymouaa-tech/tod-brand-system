# TOD by beIN — Brand System v2.0

The operating brand system for **TOD by beIN** — the streaming destination from beIN Media Group.

**Master signature:** #1 Sports & Stories

## What's inside

Single-file HTML brand book (`index.html`) covering:

- **Modules 01–10** — Brand on a Page · Foundations · Architecture · Verbal Identity · Visual Identity · Identity System (Chapter 03) · Experience Identity · Channel Playbooks · Co-Branding · Localization · Governance
- **Appendices A–E** — Role Quick-Starts · Templates Library · Glossary · Change Log · MENA Calendar

## Running locally

Just open `index.html` in any modern browser, or serve the folder:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deployment

Hosted on GitHub Pages. To redeploy, push to `main` and GitHub Pages will rebuild automatically.
